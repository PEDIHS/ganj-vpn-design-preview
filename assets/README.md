# Brand assets

The **official Ganj VPN logo must be supplied directly to the design tool as an image asset**.

Do not redraw, regenerate, simplify or reinterpret the mark.

Expected visual identity of the official asset:

- Shield / G monogram
- Central emerald diamond
- Emerald green and metallic gold construction
- Transparent background preferred

When using Google Stitch, add the official logo image with **Upload code, images, fonts and logos** alongside the public GitHub repository.

The public design-preview repository intentionally does not embed a recreated logo because the original user-supplied asset must remain exact.
